## Selected Work

### Dhakaiaa Jamdani — Ecommerce Platform

A full-stack ecommerce platform built for a traditional Bangladeshi textile brand, covering the complete customer experience from product discovery to checkout and order management.

The platform handles product catalogue management, user authentication, shopping cart and checkout flows, transactional email notifications, admin order management and database-backed operations. The live storefront is deployed and actively used.

**Stack:** Next.js · TypeScript · React · Supabase · PostgreSQL · Redux Toolkit · Tailwind CSS · Resend · Vercel

[Live Site](https://dhakaiaajamdani.com.bd/) · [Source](https://github.com/AsifShawon/dhakaiaa-jamdani-next-js)

### AI-Powered Physics Chatbot

A domain-focused AI assistant that uses Retrieval-Augmented Generation to answer physics questions accurately. The system retrieves relevant context from a curated knowledge base and passes it to Google's Gemini API to generate grounded, context-aware responses.

Built with a Flask backend, LangChain for orchestration and a vector database for similarity search. The project demonstrates AI as a practical feature rather than a prototype — combining retrieval, generation and domain specificity in a working application.

**Key work:** RAG pipeline design, LangChain orchestration, Gemini API integration, Flask backend, vector database retrieval

**Stack:** Python · LangChain · RAG · Gemini API · Flask · Vector Databases · NLP

[Source](https://github.com/AsifShawon/physics-bot)

---

### AI CGPA Calculator — Transcript Processing Tool

A practical AI tool that accepts uploaded grade sheets and transcript documents (images or PDFs), uses AI to extract individual courses and grade data, and computes CGPA automatically. Users can review, correct and export the results.

This project demonstrates AI as a product feature delivering real utility — document understanding, structured data extraction and calculation logic working together in a single tool.

**Key work:** AI document parsing, PDF/image processing, grade extraction, CGPA calculation engine, export functionality

**Stack:** React · Next.js · TypeScript · Gemini API · PDF.js · JavaScript

[Live Tool](https://withshawon.vercel.app/hello/tools/calculate-cgpa)
